## 기본 스토어 등록정보

### 짧은 설명

`수유·수면·기저귀부터 성장까지, 아기의 하루 리듬을 한눈에 기록해요.`

### 전체 설명

앙팡타임은 보호자가 아기의 하루와 일주일 흐름을 빠르게 기록하고 이해할 수 있도록 만든 육아 기록
앱입니다.

돌봄 중에는 복잡한 입력보다 바로 기록하는 일이 중요합니다. 홈에서 자주 쓰는 기록을 빠르게 남기고,
저장 직후에는 수정하거나 실수를 취소할 수 있습니다.

주요 기능

- 수유, 수면, 기저귀, 약, 체온, 이유식, 놀이, 성장 기록
- 최근 사용 순서와 이전 입력값을 활용한 빠른 기록
- 오늘의 섭취량, 수면 시간, 기저귀 횟수 요약
- 24시간 리듬에서 수유와 수면 순서 확인
- 기록이 충분할 때만 보여주는 간격·추세 분석
- 최근 7일의 기록된 날을 기준으로 한 주간 요약
- 초대 코드를 이용한 가족 공동 기록
- 홈 화면 위젯에서 마지막 수유와 현재 수면 상태 확인
- 수유 알림과 앱 내 계정 삭제

기록이 적은 날에는 억지로 평균이나 경고를 만들지 않고, 지금 확인할 수 있는 사실과 다음에 남기면 좋은
기록을 안내합니다. 의료 진단을 제공하는 앱이 아니며, 건강 상태가 걱정되는 경우 의료 전문가와 상담해야
합니다.

### 심사 안내문

앙팡타임은 보호자가 아기의 수유, 수면, 기저귀, 약, 체온, 이유식, 놀이 및 성장 기록을 관리하는
앱입니다. 로그인 후 홈에서 오늘 요약과 빠른 기록을 확인할 수 있으며, 패턴에서 24시간 리듬, 분석에서
최근 7일 흐름을 확인할 수 있습니다. 앱 내 프로필 화면에서 계정을 삭제할 수 있습니다.

Android 홈 화면 위젯은 앱 로그인과 아기 선택 후 추가하면 마지막 수유, 오늘 섭취량, 수면 상태,
기저귀 횟수를 표시합니다.

## 타겟층과 콘텐츠

- 권장 대상 연령: `18세 이상`
- 아동 대상 앱 여부: `아니요`
- 근거: 실제 사용자는 아기가 아니라 아기의 정보를 입력·관리하는 성인 보호자다.
- `[VERIFY_BEFORE_SUBMISSION]` 스토어 이미지와 문구가 아동이 직접 사용하는 앱처럼 보이지 않는지 확인
- 콘텐츠 등급: 설문을 사실대로 완료하고 결과를 사용한다. 폭력·성적 콘텐츠·도박 등은 현재 코드에 없다.
- 의료 앱 주장: `아니요`; 기록과 비의료적 요약만 제공

아동을 대상 연령에 포함하면 Families 정책과 아동 대상 광고 요건이 추가되므로, 단순히 아기 관련
앱이라는 이유로 아동 연령대를 선택하지 않는다.

## 광고 선언

- 앱에 광고가 포함되는가: `예`
- 개발·내부 테스트: 테스트 광고만 사용
- 광고 위치: 빠른 기록/입력 도중이 아닌 홈·분석·성장·프로필 콘텐츠 뒤
- `[VERIFY_BEFORE_SUBMISSION]` 광고가 하단 탭, 저장 스낵바, 계정 삭제, 기록 입력을 가리지 않는지 실기기 확인
- `[VERIFY_BEFORE_SUBMISSION]` 제공되는 광고의 성숙도가 앱 콘텐츠보다 높지 않도록 AdMob 차단 제어 확인
