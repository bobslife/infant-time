# 이유식 토핑 기록과 오늘 기록 없음 카드

## 구현

- 초기/중기/후기 직접 선택. 저장된 최신 이유식 기록의 단계를 우선 기본값으로 사용하고, 저장된 기록이 없을 때만 아기 ID별 브라우저 선택값을 사용한다. 공유 아기를 여러 기기에서 기록해도 마지막으로 저장한 단계가 다음 입력에 반영된다.
- 초기 8종, 중기 12종, 후기 16종의 누적 표시 목록. 쌀·오트밀·애호박·소고기·감자·단호박·당근·브로콜리 / 닭고기·두부·시금치·양배추 / 달걀·생선·버섯·양파. 단계 구분은 UI 프리셋이며 월령별 섭취 가능 여부를 의미하지 않는다. 모든 단계에서 전체 재료 선택이 가능하다.
- 저장소 자체 제작 SVG 16종. 기존 24×24 단색 인터페이스 아이콘과 일관된 크기, 토핑 이름 병기.
- 다중 선택·개별 해제·단계 변경 시 선택 보존. 새 기록은 조합을 빈 상태로 시작해 이전 식사를 잘못 복사하지 않는다. 기존 이유식 이름·양·반응·메모 편집 유지.
- `mealStage` / `mealToppings`를 로컬 및 Supabase 저장/수정/조회에 연결. DB에는 `meal_stage` / `meal_toppings` 추가. 빈 배열은 기존 기록에 자동 적용되며, 기존 텍스트 이름을 임의로 토핑으로 해석하지 않는다.
- 이유식 기록 카드는 기록 시간, 이름, 토핑 아이콘, g을 세로 가운데에 맞추고 높이를 자동 확장한다. 사용자가 이름을 입력하면 `이유식 (소고기 채소죽)` 형식으로 제목에 합치며, 자동 생성됐던 토핑 조합 이름은 제목으로 반복하지 않는다. 토핑이 4개 이상이면 3개까지만 보여주고 `+N개`로 접어 목록 높이가 과도하게 늘지 않게 한다.
- 긴 입력 화면에서는 재료 선택 영역을 접고 펼칠 수 있다. 기존 기록을 편집할 때는 선택된 개수를 접힌 버튼에 표시한다.
- 홈: 당일 기록이 0건이면 마지막 기록/예측 대신 빈 카드와 기록 버튼을 표시한다. 오늘 범위는 현지 자정 이상, 다음 자정 미만. 자정 타이머와 앱 복귀/포커스 갱신 적용.

## 기록 없음 확인

운영 홈의 `src/features/meals/homeIntakePreview.ts`는 `SHOW_EMPTY_INTAKE_PREVIEW = false`로 복구했다. 실제 현지 날짜의 이유식·수유 기록이 0건일 때만 기록 없음 카드가 표시된다.

`http://localhost:3000/tests/meal-preview.html`은 별도의 개발 확인 화면이다. 홈 탭에서는 기록 없음 상태를 계속 강제로 보여주어 회귀 확인에 쓸 수 있다. 로그인이나 실제 계정 데이터 접근 없이 메모리에서 입력/수정/목록을 확인할 수 있고 새로고침하면 테스트 기록은 사라진다. Vite 프로덕션 엔트리에 포함되지 않는다.

## DB 적용 및 검증

- 연결된 infant-time 프로젝트에 `20260920121927_meal_toppings` 적용 완료. 기존 사용자 데이터, RLS 정책, 함수 및 권한 변경 없음.
- 실제 DB의 테이블 구조를 복제한 임시 테이블에서 생성/수정/잘못된 단계 거부를 검증한 후 트랜잭션 전체 롤백. 사용자 기록을 테스트용으로 추가하지 않았다.
- 기존 security advisor의 account_histories 정책 안내, 기존 SECURITY DEFINER 함수 노출 및 비밀번호 유출 방지 설정 경고는 이번 필드 추가와 무관하며 범위 밖 변경을 하지 않았다.
- 배열 저장 방식은 [Supabase 공식 배열 문서](https://supabase.com/docs/guides/database/arrays)를 확인했다.

## 확인 결과

- `npm run build`
- `node scripts/check-mixed-intake.mjs`
- `node scripts/check-meal-toppings.mjs`: 단계별 목록, 최신 저장 단계 우선, 파일 존재, 아기별 기억, 토핑 축약, 이유식 이름 제목 형식, 로컬 저장/재조회/수정/해제, 원격 payload/response 매핑, 구 기록 표시, 자정·미래 날짜 제외, 빈 카드 강제 표시/해제
- 실제 브라우저 390px 폭: 재료 목록 접기와 선택 수 유지, 이유식 이름 입력, 5개 토핑+85g 저장, `이유식 (소고기 채소죽)` 제목과 3개 토핑+`+2개` 표시, 가운데 정렬, 빈 홈 카드 시각 확인. 콘솔 경고·오류 없음.
- 웹 배포와 네이티브 빌드는 수행하지 않았다. 실제 로그인 세션에서 앱→Supabase 전체 저장 경로는 미검증이며, 원격 매핑 회귀 검사 및 DB 임시 테이블 왕복으로 분리 검증했다.
