# 리듬·분석 통합 미리보기 기획

## 목표

- 하단의 `리듬`과 `분석`을 `리듬` 한 탭으로 합친다.
- 사용자가 날짜별 변화를 처음 봐도 축과 색을 다시 해석하지 않게 한다.
- 핵심 지표는 날짜별 평균 간격과 날짜별 총량만 유지한다.

## 화면 구조

1. 최근 7일 기간 선택
2. 평균 간격 / 총량 전환
3. 기존 분석 탭의 막대그래프 스타일을 유지한 분유·모유·이유식·수면 4개 행
4. 모든 막대 위에 해당 날짜의 값을 표시하고, 막대 선택 시 네 항목의 간격과 총량을 함께 보여주는 상세 카드
5. 최근 평균과 차이가 큰 날이나 기록 누락을 알려주는 `리듬 신호`

기존 원형 24시간 리듬과 분석 카드들을 한 화면에 그대로 이어 붙이지 않는다. 날짜 위치가 네 행에서 고정된 작은 다중 막대그래프를 사용해 같은 날의 높고 낮음을 수직으로 비교한다. 선택한 날짜의 막대에는 기존 분석 그래프처럼 외곽선을 표시한다.

## 지표 정의

- 분유 평균 간격: 연속 분유 시작 시각 사이의 평균
- 모유 평균 간격: 연속 모유 시작 시각 사이의 평균
- 이유식 평균 간격: 연속 이유식 시작 시각 사이의 평균
- 수면 평균 간격: 이전 수면 종료부터 다음 수면 시작까지의 평균 깨어있는 시간
- 분유 총량: 하루 섭취 ml 합계
- 모유 총량: 하루 수유 시간 합계
- 이유식 총량: 하루 섭취 g 합계
- 수면 총량: 하루 수면 시간 합계

하루에 해당 유형이 한 번뿐이면 평균 간격을 계산할 수 없으므로 `간격 계산 전`으로 표시한다. 기록이 없으면 0으로 그리지 않고 빈 점으로 표시해 실제 0과 기록 누락을 구분한다.

## 추가 기능: 리듬 신호

선택한 날짜가 최근 7일 평균 범위를 크게 벗어나거나 기록이 비어 있을 때만 짧게 알려준다. 의료 판단이나 원인 추정은 하지 않고 `수면 총량이 최근 평균보다 12% 적어요`처럼 기록에서 직접 계산한 변화만 설명한다.

## 운영 반영

- 하단 탭을 `홈 / 리듬 / 성장 / 프로필` 네 개로 변경했다.
- 별도 분석 탭과 기존 원형 리듬 화면을 제거하고 통합 컴포넌트를 리듬 탭에 연결했다.
- 조회 기간은 최근 7일로 고정했다.
- 미리보기와 운영 화면이 같은 `RhythmAnalysisCards` 컴포넌트를 사용한다.
