# 수유·이유식 혼합 기록 개선

## 검토 결과

- 홈: 이유식 기록이 한 건이라도 있으면 마지막 수유, 다음 수유 예측, 오늘 수유량이 이유식 화면으로 대체됐다.
- 분석: 최초 이유식 날짜 이후에는 수유 타임라인·간격·주간 분유/모유 그래프가 가려졌다. 주간 수유 평균의 분모도 이유식 기록일에 종속됐다.
- iOS 중형 위젯: 마지막 이유식 기록 유무로 수유 상태와 총량이 숨겨졌다.
- 기록 입력, 기록 목록, 리듬 화면, 위젯 전달 데이터는 이미 수유와 이유식을 함께 지원한다. 이번 작업에서 변경하지 않았다.

## 개선 내용

- 홈은 기록 이력이 있는 수유와 이유식을 각각 표시한다. 둘 다 있으면 마지막 기록과 오늘 총량을 함께 보여주며 수유 예측/간격 설정도 유지한다. 기록이 전혀 없으면 기존 수유 시작 안내를 유지한다.
- 분석의 당일 총량은 선택 날짜의 기록 기준, 주간 요약과 섭취 상세는 선택 날짜까지 최근 7일의 기록 기준으로 표시한다. 과거 이유식 한 건으로 영구적인 모드 전환이 일어나지 않는다.
- 수유와 이유식의 타임라인, 평균 간격, 전일 대비 총량을 별도로 계산한다. 혼합 기록에는 두 종류의 간격을 함께 설명한다.
- 분유·모유·이유식 주간 평균은 각 종류가 기록된 날짜만 분모로 사용한다. 양이 0이거나 미입력이어도 기록 자체가 있으면 노출한다.
- 분석에 한 건만 있어도 요약/타임라인과 최근 이력을 표시한다. 간격은 두 건, 날짜별 추세는 이틀이라는 기존 최소 데이터 안내를 유지한다.
- iOS 중형 위젯은 수유 예측과 마지막 이유식을 함께 배치하고 오늘 수유·이유식 총량을 별도로 표시한다. 소형 위젯은 기존 아기 프로필 카드다.

- `node scripts/check-mixed-intake.mjs`: React 서버 렌더링 회귀 검사 통과. 혼합 기록, 종류별 평균, 한 건 기록, 양 미입력, 7일 밖/미래 이유식의 영향 차단, 빈 날짜, 홈 동시 노출 포함.
- `swiftc -frontend -parse ios/App/App/InfantTimeWidget/InfantTimeWidget.swift`: 문법 검사 통과.
- `git diff --check`: 통과.
- 브라우저 상호작용/화면 크기별 시각 검증과 iOS 위젯 실기기·시뮬레이터 렌더링, 네이티브 전체 빌드는 수행하지 않았다. 배포하지 않았다.
