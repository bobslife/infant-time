# Infant Time Quality Risk Register

현재 확인된 품질 리스크와 후속 대응 방향을 기록한다. 상태는 `미착수`, `진행 중`, `완료`, `보류`로 관리한다.

| 우선순위 | 리스크 | 사용자 영향 | 권장 조치 | 상태 |
| --- | --- | --- | --- | --- |
| P0 | 자동화 테스트 부재 | 수유 집계, 자정 수면 분할, 분석 계산 변경 시 회귀를 배포 전에 발견하기 어렵다. | Vitest로 순수 계산과 저장소 매핑을 우선 보호하고, 핵심 입력 흐름은 Playwright 모바일 시나리오로 추가한다. | 미착수 |
| P1 | 공동 사용자의 아기 프로필 수정 권한 불일치 | 공동 보호자에게 수정 UI가 보이지만 RLS는 소유자만 허용하여 저장 오류가 발생한다. | `baby.ownerId === user.id`일 때만 수정 UI를 노출하고 공동 보호자에게 읽기 전용 안내를 제공한다. | 미착수 |
| P1 | 공동 기록 실시간 동기화 부재 | 다른 보호자가 남긴 기록이 당겨서 새로고침하기 전까지 보이지 않는다. | 선택 아기의 `events` 변경을 Supabase Realtime으로 구독하고 재연결·중복 이벤트 처리를 추가한다. | 미착수 |
| P1 | 성장 기록 수정·삭제 부재 | 잘못 입력한 몸무게·키·머리둘레를 앱에서 정정할 수 없다. | 성장 기록 목록에 수정·삭제 액션을 추가하고 저장소 및 RLS 정책을 확인한다. | 미착수 |
| P2 | PWA 서비스 워커 비활성화 | 웹 설치 환경에서 오프라인 캐시와 PWA 업데이트 기능을 사용할 수 없다. | 네이티브 원격 WebView 운영 정책과 PWA 지원 정책을 먼저 확정한 뒤 서비스 워커를 복구하거나 관련 자산을 제거한다. | 보류 |
| P2 | 미사용 `QuickEntrySheet` 잔존 | 입력 UI가 이중으로 존재해 향후 수정 누락과 유지보수 혼선을 만들 수 있다. | 현재 `EventInputScreen`으로 기능이 완전히 대체됐는지 확인한 뒤 컴포넌트와 관련 스타일을 제거한다. | 미착수 |

## 운영 원칙

- P0는 배포 차단 가능성이 있는 항목으로 우선 처리한다.
- 신규 기능은 관련 P0/P1 리스크를 악화시키지 않는 범위에서 구현한다.
- 상태 변경 시 근거가 되는 PR, 커밋 또는 검증 결과를 항목 아래에 추가한다.
