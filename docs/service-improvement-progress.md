# Service Improvement Progress

기준 백로그: `docs/service-improvement-handoff.md`

## 구현 완료

### 반복 기록

- 기록 타입별 최근 입력값 재사용
  - 분유량
  - 기저귀 종류와 대변 상세
  - 약 이름과 용량
  - 체온 측정 위치
  - 이유식 종류, 양, 반응
- 모유 시간, 체온 숫자, 기록 시각, 자유 메모는 재사용하지 않는다.
- 진행 중 수면과 놀이는 홈 빠른 기록에서 경과 시간과 함께 종료할 수 있다.
- 저장 후 `수정`과 `취소`, 삭제 후 `되돌리기`를 제공한다.
- 저장소 오류가 발생하면 성공 처리하지 않고 입력값을 유지한다.
- 최근 30개 기록을 기준으로 자주 사용하는 빠른 기록 4개를 앞에 배치한다.
- 빠른 기록 영역에 다음 카드와 edge fade를 노출한다.

### 패턴과 분석

- 패턴·분석 공통 날짜 탐색: 이전 날, 다음 날, 오늘, 날짜 직접 선택
- 미래 날짜 이동 제한
- 기록이 없는 날은 0 카드와 0 차트 대신 수유·수면 CTA를 표시한다.
- 기록 1개인 날은 하루 전체를 단정하지 않고 해당 기록과 다음 기록 행동만 보여준다.
- 패턴 원형 segment와 타임라인에서 원기록을 선택할 수 있다.
- 선택 기록의 시간·핵심값을 확인하고 바로 수정할 수 있다.
- 분석 근거 기록에서 같은 날짜의 패턴으로 이동하고 해당 기록을 강조한다.
- 패턴에서 같은 날짜의 분석으로 돌아갈 수 있다.
- 분석 차트는 데이터 조건을 만족할 때만 표시한다.
  - 당일 타임라인: 해당 기록 1건 이상
  - 평균 간격: 해당 기록 2건 이상
  - 7일 추세: 값이 있는 날 2일 이상
  - 대변 색상: 색상 기록 1건 이상
- 최근 7일은 전체 7일을 0으로 나누지 않고 실제 기록한 날 기준 평균을 표시한다.
- 대표 Insight가 수유 간격 또는 수면 변화를 말할 때 실제 근거 기록을 함께 연결한다.
- 최근 비교 가능한 날이 3일 이상일 때만 긴 수유 공백, 늦어진 첫 수유, 크게 달라진 수면 구간을 `평소와 다른 흐름`으로 표시한다.
- 비교 강조는 원기록과 연결하며 의료적 경고 표현을 사용하지 않는다.
- 홈 광고는 빠른 기록과 최근 기록이 끝난 뒤에 표시한다.
- 분석 광고는 대표 Insight, 지표, 상세 분석이 끝난 뒤에 표시한다.

## 보호자 관점 점검 결과

- 한 건뿐인 기록으로 “평소보다 부족하다” 같은 결론을 만들지 않는다.
- 기록이 부족한 화면은 어떤 기록을 더 남기면 무엇을 알 수 있는지 설명한다.
- 과거 날짜의 수면·놀이 CTA는 종료 시각을 기본 제공해 오래 열린 진행형 기록을 만들지 않는다.
- 저장 실수는 최근 기록 목록을 다시 찾지 않고 즉시 복구할 수 있다.
- 하루 요약은 수유·수면의 순서와 긴 공백을 찾는 데 집중한다.
- 주간 요약은 기록하지 않은 날의 0을 평균에 섞지 않아 실제 돌봄 흐름을 왜곡하지 않는다.
- 패턴에서 잘못된 시간을 발견했을 때 홈으로 돌아가 원기록을 찾을 필요가 없다.
