# Infant Time Current Feature Inventory

이 문서는 현재 구현된 회원관리, 로그인 처리, 탭별 기능을 정리한 기준 자료이다. 기획자는 새 기능이나 개선점을 구상할 때 이 문서의 현재 동작을 먼저 확인하고, 테스터는 여기에 명시된 기능을 테스트 범위의 기본 목록으로 사용한다.

## 1. 진입, 인증, 저장 모드

### 앱 진입

- `/privacy` 경로는 개인정보처리방침 화면을 표시한다.
- `/support` 경로는 고객지원 화면을 표시한다.
- 필수 업데이트 조건이 감지되면 일반 앱 화면 대신 강제 업데이트 화면을 표시한다.
- 앱 데이터 로딩 중에는 로고 중심의 로딩 화면을 표시한다.
- 오프라인 상태에서는 오프라인 안내 화면을 표시하고, 재시도 또는 로컬 미리보기 진입을 제공한다.
- 로그인한 사용자가 바뀌면 홈 탭으로 이동하고 입력 모달/편집 상태를 초기화한다.
- 앱 화면 상단에서 아래로 당기면 기준 거리 이상에서 데이터 새로고침을 실행한다.

### 로그인/회원가입

- 로그인 화면은 `로그인`과 `회원가입` 모드를 전환한다.
- 로그인 입력값은 이메일과 비밀번호이며, 이메일은 trim 처리된다.
- 회원가입 입력값은 보호자 이름, 이메일, 비밀번호, 비밀번호 확인이다.
- 비밀번호는 6자 이상이어야 한다.
- 회원가입 시 비밀번호와 비밀번호 확인이 다르면 로컬 오류 메시지를 표시하고 제출하지 않는다.
- Supabase가 설정된 환경에서는 Supabase Auth로 회원가입/로그인을 처리한다.
- 회원가입 후 세션이 바로 없으면 같은 이메일/비밀번호로 자동 로그인을 시도한다.
- 자동 로그인도 실패하면 이메일 확인 설정 관련 안내 오류를 표시한다.
- 인증 오류는 로그인 화면의 오류 영역에 표시한다.
- Supabase가 없는 환경에서는 로컬 사용자로 로그인 처리되고, `로컬 미리보기로 확인` 버튼이 노출된다.
- 로그인 화면 하단에서 개인정보처리방침과 고객지원으로 이동할 수 있다.

### 저장 모드

- Supabase 사용자는 `profiles`, `babies`, `baby_members`, `events`, `growth_records` 기반으로 데이터를 저장/조회한다.
- Supabase 로그인 후 사용자 프로필은 `profiles`에 upsert 된다.
- 로컬 미리보기 사용자는 브라우저 `localStorage`에 아기, 이벤트, 성장 기록, 선택한 아기 정보를 저장한다.
- 로컬 이벤트 저장소가 비어 있으면 목업 이벤트를 초기 데이터로 넣는다.
- Supabase 사용자의 선택한 아기 ID는 사용자별 localStorage 키에 저장한다.
- 로컬 사용자의 선택한 아기 ID는 로컬 전용 키에 저장한다.

## 2. 아기/회원 관리

### 최초 아기 설정

- 로그인했지만 선택 가능한 아기가 없으면 최초 설정 화면을 표시한다.
- 최초 설정은 `코드 등록`과 `새 아기 추가` 모드를 지원한다.
- 코드 등록은 8자리 초대 코드를 입력해야 제출할 수 있다.
- 초대 코드는 영문/숫자만 허용하고, 입력 중 대문자로 변환하며, 최대 8자리로 제한한다.
- 새 아기 추가는 아기 이름, 생일, 성별을 입력한다.
- 아기 이름은 필수이며 공백만 있으면 제출 버튼이 비활성화된다.
- 성별은 여아/남아 중 선택하며 기본값은 여아이다.
- 새 아기를 만들면 자동으로 해당 아기가 선택되고 빈 이벤트 목록으로 시작한다.

### 프로필 탭의 아기 관리

- 현재 아기의 이름, 나이, 생일, 등록일, 초대 코드를 표시한다.
- 성별 수정 모드를 열고 여아/남아를 선택하면 즉시 저장한다.
- 아이 변경 모달에서 사용자가 접근 가능한 아기 목록을 표시한다.
- 아기 목록에서 다른 아기를 선택하면 해당 아기의 이벤트를 불러오고 모달을 닫는다.
- 아이 변경 모달에서 아기를 직접 추가하거나 초대 코드로 기존 아기에 참여할 수 있다.
- 아기 직접 추가 입력은 이름, 생일, 성별을 받는다.
- 초대 코드 등록은 8자리 영문/숫자 대문자 코드만 제출 가능하다.
- Supabase에서는 소유 아기와 멤버로 참여한 아기를 함께 조회한다.
- 초대 코드 참여는 Supabase RPC 또는 로컬 저장소 조회로 처리한다.

### 계정 관리

- 프로필 탭에서 보호자 이름, 로그인 계정, 저장 방식을 표시한다.
- 저장 방식은 `Supabase` 또는 `로컬 미리보기`로 표시한다.
- 로그아웃 버튼을 제공한다.
- Supabase 사용자가 로그아웃하면 인증 세션을 종료하고 앱 상태를 초기화한다.
- Supabase가 없는 환경의 로컬 사용자는 로그아웃 후 다시 로컬 사용자 데이터를 로드한다.
- 회원 탈퇴 버튼을 누르면 확인 모달을 표시한다.
- 회원 탈퇴 모달은 삭제 안내와 확인 문구 입력 필드를 제공한다.
- 확인 문구가 정확히 `탈퇴`일 때만 영구 삭제 버튼이 활성화된다.
- Supabase 회원 탈퇴는 `delete_current_user_account` RPC 호출 후 로그아웃하고 선택 아기 저장값을 삭제한다.
- 로컬 회원 탈퇴는 로컬 이벤트, 아기, 선택 아기 저장값을 삭제한다.
- 회원 탈퇴 성공 후 아기/이벤트 상태는 비워진다.
- 프로필 탭에서 개인정보처리방침, 고객지원 링크를 제공한다.
- 프로필 탭은 설치된 앱 버전을 조회해 표시하고, 실패 시 확인 불가로 표시한다.

## 3. 공통 기록 기능

### 기록 타입

- 지원 기록 타입은 수유, 수면, 기저귀, 약, 체온, 이유식, 메모, 목욕, 놀이이다.
- 기존 데이터 호환을 위해 소변(`pee`)과 대변(`poop`) 이벤트도 표시/집계한다.
- 홈의 빠른 기록 버튼은 모유, 분유, 이유식, 수면, 기저귀, 놀이, 목욕, 약, 체온 순서로 제공한다.
- 홈의 추가 기록 카드에서는 현재 모드에 따라 수유/이유식, 기저귀, 약, 체온, 놀이, 목욕 진입을 제공한다.
- 기록 저장/수정 후 입력 모달을 닫고 홈 상단으로 스크롤하며 저장 토스트를 표시한다.
- 저장 중에는 중복 제출을 방지한다.
- 저장 성공 시 가능한 환경에서 짧은 진동 피드백을 실행한다.

### 입력 모달

- 기록 모달은 신규 기록과 기존 기록 수정에 모두 사용된다.
- 기존 기록을 누르면 해당 기록 값이 입력 필드에 채워진다.
- `pee`/`poop` 기존 기록은 기저귀 타입으로 정규화해 편집한다.
- 기록 시간은 날짜와 시간을 분리해서 입력한다.
- 수면과 놀이는 시작 날짜/시간과 종료 날짜/시간을 입력할 수 있다.
- 종료 시간이 시작 시간보다 빠르면 저장하지 않고 오류 토스트를 표시한다.
- 체온은 34도 이상 43도 이하만 유효하다.
- 메모는 공백 제거 후 저장하며, 비어 있으면 저장 값에서 제외한다.

### 타입별 입력 상세

- 수유: 빠른 용량 70, 100, 130, 170, 200, 230ml 버튼을 제공한다.
- 수유: -10/+10 스테퍼로 0~300ml 범위에서 조정한다.
- 모유와 분유는 홈에서 별도 버튼과 별도 입력 모달로 진입한다.
- 분유: 최근 5개 분유의 평균, 직전 분유량 대비 증감 안내를 표시한다.
- 모유: 왼쪽과 오른쪽 수유 시간을 각각 0~120분 범위에서 입력한다.
- 모유: 좌우 합계가 1분 이상이어야 저장할 수 있다.
- 수면: 진행 중 수면이 없으면 수면 시작 기록을 저장한다.
- 수면: 진행 중 수면이 있으면 해당 수면의 종료 시간을 저장한다.
- 수면: 기존 진행 중 수면을 편집할 때 종료 시간이 비어 있으면 현재 시각으로 종료 저장할 수 있다.
- 수면: 홈 요약 카드의 `깨우기` 버튼으로 진행 중 수면을 즉시 종료한다.
- 수면: 자정을 넘는 종료 수면은 날짜별 구간으로 분할 저장한다.
- 수면: 전날 시작된 미종료 수면은 앱 로드 시 자정까지 닫고 오늘 0시 시작 수면을 이어서 생성한다.
- 기저귀: 소변, 대변, 둘다를 선택한다.
- 기저귀: 대변 또는 둘다일 때 대변 양(적음/보통/많음)과 색상(노랑/초록/갈색/진갈/다홍)을 기록한다.
- 약: 약 이름과 용량을 선택 입력한다.
- 체온: 체온 숫자와 측정 위치(이마/귀/겨드랑이)를 입력한다.
- 체온: 입력값에 따라 정상 범위, 미열 경향, 고열 경향 안내를 표시한다.
- 이유식: 음식 이름, 섭취량 g, 반응(잘 먹음/보통/적게 먹음/반응 있음)을 기록한다.
- 목욕: 날짜와 시간 중심으로 목욕 기록을 남긴다.
- 놀이: 시작/종료 시간과 메모를 기록하고, 종료 시간이 없으면 진행 중으로 표시한다.
- 메모: 메모 내용을 기록하거나 기존 메모를 수정한다.

### 기록 목록

- 홈 탭의 최근 기록 목록은 날짜별로 그룹화한다.
- 날짜 그룹 헤더에는 날짜, 총 수유량, 총 수면 시간을 표시한다.
- 기록은 발생 시간 역순으로 정렬한다.
- 한 번 탭하면 기록 수정 모달을 연다.
- 왼쪽으로 80px 이상 스와이프하면 삭제 버튼을 노출한다.
- 삭제 버튼을 누르면 해당 기록을 삭제하고 목록에서 제거한다.
- 처음에는 7일치 날짜 그룹을 표시하고, 스크롤 하단에 가까워지면 이전 7일 그룹을 추가로 로드한다.
- 기록이 없으면 빈 상태 문구를 표시한다.

## 4. 홈 탭

- 홈 탭은 아기 이름, 기본 프로필 이미지, 나이, 성별 아이콘을 표시한다.
- 수유 기록 기반 모드와 이유식 기록 기반 모드를 자동 전환한다.
- 이유식 기록이 하나라도 있으면 주요 흐름은 이유식 중심으로 표시한다.
- 수유 모드에서는 마지막 수유 시각, 마지막 수유 후 경과 시간, 다음 수유 예측을 표시한다.
- 마지막 수유와 수유 간격은 분유와 모유 기록을 함께 사용한다.
- 오늘 수유 요약은 분유 ml와 모유 시간을 분리해 표시한다.
- 수유 모드에서는 수유 간격 기준의 진행률 바를 표시한다.
- 수유 간격 프리셋은 180, 210, 240, 270, 300분이며, 저장된 사용자 기준값이 다르면 목록에 추가해 표시한다.
- 수유 간격은 30~720분 범위로 제한하고 localStorage 및 원격 알림 설정에 저장한다.
- 수유 예정 시간이 지나면 경고 문구를 표시한다.
- 이유식 모드에서는 마지막 이유식 시각과 경과 시간을 표시한다.
- 이유식 모드에서는 마지막 이유식 후 180분 이상이면 주의 상태를 적용한다.
- 오늘의 주요 요약으로 수유량 또는 이유식량, 수면시간을 표시한다.
- 수면 중이면 수면 상태 칩과 `깨우기` 버튼을 표시한다.
- 추가 기록 보기 토글로 기저귀, 약, 체온, 놀이, 목욕, 수유/이유식 요약 카드를 확장한다.
- 확장 요약 카드는 누르면 해당 기록 입력 모달을 연다.
- 하단 기록 영역은 주요 활동별 빠른 기록 버튼을 제공한다.
- 홈 하단에는 광고 배너가 표시된다.

## 5. 분석 탭

- 분석 탭은 선택 날짜 입력을 제공한다.
- 선택 날짜가 첫 이유식 기록일 이후이면 이유식 분석 모드로 전환한다.
- 수유/이유식, 수면, 기저귀의 핵심 지표 카드를 표시한다.
- 수유 분석은 총 수유 횟수, 분유 총량, 모유 총 시간을 분리해 표시한다.
- 선택 날짜와 전날의 수유량/이유식량, 수면 시간 차이를 표시한다.
- 수유 또는 이유식 기록 간격의 평균을 계산한다.
- 최근 7일 데이터를 기준으로 수유량/이유식량, 평균 간격, 수면 시간 추이를 만든다.
- 선택 날짜의 수유/이유식 타임라인 차트를 표시한다.
- 선택 날짜에 수유/이유식 기록이 2개 이상일 때 날짜별 평균 간격 차트를 표시한다.
- 최근 7일 수유량 또는 이유식량 막대 차트를 표시한다.
- 수유 모드의 최근 7일 추세는 분유량과 모유 시간을 별도 차트로 표시한다.
- 최근 7일 수면 시간 막대 차트를 표시한다.
- 대변 색상 분포를 표시한다.
- 상세 분석은 섭취, 수면, 기저귀 구역을 전환해 표시한다.
- 기록 상황에 따라 Insight 카드의 톤과 문구를 표시한다.
- 오늘 날짜를 분석할 때는 진행 중 수면/놀이 시간을 현재 시각 기준으로 반영한다.
- 분석 하단에는 광고 배너와 기록 보강 안내 문구가 표시된다.

## 6. 패턴 탭

- 패턴 탭은 선택 날짜 입력을 제공한다.
- 선택 날짜의 기록을 24시간 원형 리듬 차트로 표시한다.
- 원형 차트는 수면, 수유, 기저귀, 세부 기록의 링으로 나뉜다.
- 수유 링에서는 모유와 분유를 서로 다른 색상, 라벨, 범례로 구분한다.
- 세부 기록에는 약, 체온, 이유식, 놀이, 목욕, 메모가 포함된다.
- 수면/놀이는 실제 종료 시간이 있으면 해당 기간을 표시하고, 종료 시간이 없으면 현재 시각 기준으로 계산한다.
- 기간이 없는 기록은 타입별 최소 표시 길이를 적용해 차트에 보이게 한다.
- 날짜 경계를 넘는 수면/놀이 기록은 선택 날짜에 보이는 구간만 표시한다.
- 차트 중앙에는 기록 개수, 수유 횟수, 수면 시간을 표시한다.
- 기록 타입 범례를 표시한다.
- 패턴 Insight는 기록 없음, 수유/수면 부족, 평소 대비 수유량/수면 시간 차이, 긴 수유 공백, 안정적인 리듬, 기저귀/놀이/이유식 기록 여부 등을 기준으로 가장 우선순위 높은 문구를 표시한다.
- 시간대별 리듬 타임라인을 표시한다.
- 패턴 요약으로 수유 횟수/총량, 수면 시간/횟수, 활동 횟수/놀이 시간/목욕 횟수를 표시한다.
- 패턴 요약에서는 모유 횟수/총 시간과 분유 횟수/총량을 별도 카드로 표시한다.
- 선택 날짜에 놀이 메모가 있으면 최근 놀이 메모를 별도 카드로 표시한다.

## 7. 성장 탭

- 성장 탭은 현재 아기의 성장 기록을 조회한다.
- Supabase 사용자는 `growth_records`에서 성장 기록을 조회/저장한다.
- 로컬 사용자는 아기별 localStorage 키에 성장 기록을 저장한다.
- 최신 기록과 직전 기록을 기준으로 몸무게, 키, 머리둘레의 최신값과 최근 변화량을 표시한다.
- 성장 기록이 2개 이상이면 몸무게, 키, 머리둘레 라인 차트를 표시한다.
- 성장 기록이 2개 미만이면 빈 상태 문구를 표시한다.
- 성장 기록 추가 폼은 측정일, 몸무게 kg, 키 cm, 머리둘레 cm, 메모를 입력한다.
- 몸무게/키/머리둘레는 0 이상 숫자이며 0.1 단위 입력을 지원한다.
- 저장 후 입력값을 초기화하고 목록/차트를 갱신한다.
- 성장 탭 하단에는 광고 배너가 표시된다.

## 8. 프로필 탭

- 프로필 탭은 아기 프로필 패널, 계정 정보 패널, 앱 정보 패널로 구성된다.
- 아기 프로필 패널은 프로필 수정 토글과 아이 변경 진입을 제공한다.
- 계정 정보 패널은 보호자 이름, 로그인 이메일, 저장 방식을 표시한다.
- 계정 정보 패널은 개인정보처리방침, 고객지원, 로그아웃, 회원 탈퇴 액션을 제공한다.
- 앱 정보 패널은 설치된 앱 버전을 표시한다.
- 아이 변경 모달이 열려 있지 않을 때 프로필 하단 광고 배너를 표시한다.

## 9. 알림, 위젯, 광고

- 사용자가 로그인하고 아기가 선택되면 수유 알림 권한 상태를 확인한다.
- APNs가 지원되지 않으면 알림 권한 흐름을 중단한다.
- 권한이 이미 허용되어 있으면 APNs 토큰을 동기화하고 수유 알림 간격을 저장한다.
- 권한 요청을 아직 처리하지 않았으면 권한 요청 또는 설정 안내 모드를 표시한다.
- 사용자가 알림 허용을 선택하면 APNs 토큰 등록, 알림 간격 저장, 토스트 표시를 수행한다.
- 사용자가 알림 안내를 닫으면 localStorage에 dismissed 상태를 저장한다.
- 아기별 수유 알림 간격은 localStorage와 원격 저장소에서 로드/저장한다.
- 로그인/아기/이벤트/수유 간격이 준비되면 위젯 요약을 동기화한다.
- 사용자나 아기가 없으면 위젯 요약을 지운다.
- 입력 모달 또는 알림 권한 모달이 열리면 AdMob 네이티브 배너 가시성을 숨기는 이벤트를 발행한다.
- 광고 모드는 환경 변수에 따라 mock 또는 AdMob 모드로 동작한다.

## 10. 테스트 기본 범위 메모

- 인증: 로그인, 회원가입, 비밀번호 확인 불일치, Supabase 미설정 로컬 미리보기, 로그아웃.
- 회원관리: 최초 아기 생성, 초대 코드 참여, 아이 전환, 성별 수정, 회원 탈퇴 확인 문구, 삭제 후 상태.
- 기록: 모든 기록 타입의 생성/수정/삭제, 필드별 저장값, 시간 검증, 체온 범위 검증, 중복 제출 방지.
- 수면/놀이: 진행 중 상태, 종료 처리, 시작/종료 역전 오류, 자정 경계 분할, 진행 중 시간 실시간 반영.
- 홈: 수유 모드/이유식 모드 전환, 수유 간격 프리셋 저장, 경고 상태, 추가 기록 토글.
- 분석: 날짜 변경, 수유/이유식 모드, 최근 7일 차트, 평균 간격 조건, 대변 색상 분포, 빈 상태.
- 패턴: 원형 차트, 타임라인, 날짜 경계 기록, 빈 상태, Insight 우선순위.
- 성장: Supabase/로컬 조회 저장, 최신/이전 차이, 2개 미만 빈 상태, 2개 이상 차트.
- 프로필: 링크, 앱 버전 표시, 광고 표시 조건, 아이 변경 모달.
- 공통: 오프라인 화면, 강제 업데이트 화면, 당겨서 새로고침, 에러 메시지, 모바일 텍스트 겹침/터치 가능성.
